# AARK Website v7 FINAL REVIEW

IMPORTANT: Open the files from THIS folder only.

Start with `index.html`. All pages now share the same sticky navigation.

At widths above 1120px the full desktop navigation is shown. At 1120px and below it switches to the hamburger menu so items never disappear or collide.


## v9 header refinement
- Purple information strip reduced to a compact bar and now scrolls away normally.
- Only the white navigation bar remains sticky while the user scrolls.
- Removed the oversized top padding created by the earlier fixed-header version.


## v11 navigation behavior
- Purple information strip scrolls away.
- White navigation becomes fixed only after it reaches the top of the viewport.
- Added a dynamic spacer so content does not jump when the nav becomes fixed.
- Works on file:// local previews as well as normal hosting.


## v16 branding
- Header now uses the exact official full-name AARK International School PNG supplied by the user.
- Removed the custom text wordmark treatment.
- Responsive sizing added for desktop, tablet and mobile.
